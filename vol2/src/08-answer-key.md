# Answer Key

Answers to all 145 practice questions in this volume, including the advanced mock exam.

A warning specific to Volume II. Many of these questions require arithmetic, and the explanations show the working. It is tempting to read the worked calculation, recognise each step, and conclude you knew it. You did not — recognising a derivation is not the same as producing one. For any calculation question you got wrong, close the key and redo the arithmetic yourself before moving on.

For the design-judgment questions, the explanation of why the *wrong* answer is attractive is usually the more valuable half. Those distractors are built from real mistakes engineers make in production, not from invented errors.
