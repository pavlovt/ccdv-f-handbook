**E10.53 — C.** *(Eval, Testing, and Debugging)* The eval and production are different problems. Born-digital PDFs from a single template exercise the text-extraction path and one layout; production is scanned paper, which exercises the vision path and every kind of variation scanning introduces — skew, noise, compression artefacts, handwriting, stamps, multi-column layout. A 97% pass rate on the wrong distribution is not evidence about the right one. The fix is to build the set from sampled production scans, stratified by quality so the bad end is represented rather than averaged away, keeping exact match where exactness matters and adding tolerance where it does not. **A** adds volume to an unrepresentative set. **B** relaxes the metric, which would raise the score without improving anything. **D** measures a ceiling that answers a question nobody asked.
